# Fotos del calendario

Coloca aquí las fotos de cada día con estos nombres:

```
dia01.jpg, dia02.jpg, dia03.jpg … dia24.jpg
```

- Formato recomendado: **JPG**, horizontal (proporción 4:3), unos 1200 × 900 px y menos de 500 KB cada una para que carguen rápido en el móvil.
- Si prefieres otro nombre o formato (`.png`, `.webp`…), cambia la ruta `photo` de ese día en `js/data.js`.
- Si una foto no existe, el calendario muestra un marco decorativo en su lugar (nunca un icono roto), así que puedes añadirlas poco a poco.
